# Tansu 利用ガイド

## 初回の設定

**フォルダへのアクセス許可**
デスクトップ、書類、ダウンロードなどを初めて開くと、macOS がアクセス許可を尋ねます。許可するまで、そのフォルダの一覧は表示されません。
保護されたフォルダに広くアクセスする必要がある場合は、「システム設定 > プライバシーとセキュリティ > フルディスクアクセス」でTansuに許可できます。

**F2・F5 を fn なしで使う**
Mac の初期設定では、F2 や F5 を押すと画面の明るさなどが変わります。fn を押さずに名前変更（F2）や更新（F5）を使うには、次の設定をオンにします。

「システム設定 > キーボード > キーボードショートカット… > ファンクションキー > F1、F2 などのキーを標準のファンクションキーとして使用」

オンにしない場合は、fn+F2、fn+F5 で同じ操作ができます。更新は Cmd+R でも行えます。

## 画面構成

上から順に、次のように並びます。

1. **タブバー**：ウィンドウ最上部。右端の「＋」でタブを追加
2. **ナビゲーション行**：戻る、進む、上へ、更新、アドレスバー、検索ボックス
3. **コマンドバー**：新規作成、切り取り、コピー、貼り付け、名前変更、共有、削除、並べ替え、表示、その他
4. **本体**：左にナビゲーションウィンドウ、中央にファイル一覧、右にプレビューウィンドウ（初期状態は非表示）
5. **ステータスバー**：項目数と選択状態、右端に詳細表示／大アイコン表示の切り替え

アドレスバーは、階層名をクリックするとそのフォルダへ移動し、「>」をクリックするとその階層にあるフォルダの一覧が出ます。空白部分をクリックするとパスを直接入力できます（`~` も使えます）。

## キー操作

コピーや貼り付けなど、WindowsでCtrlを使う主な操作にはCmdを使います。

| 操作 | キー |
|---|---|
| 開く | Enter／ダブルクリック |
| 名前変更 | F2 |
| 上の階層へ | ⌫（delete キー）／Option+↑ |
| 戻る／進む | Option+←／Option+→、Cmd+[／Cmd+] |
| 削除（ゴミ箱へ） | Cmd+⌫／fn+⌫（前方削除）／外付けキーボードの Delete キー |
| コピー／切り取り／貼り付け | Cmd+C／Cmd+X／Cmd+V |
| 元に戻す | Cmd+Z |
| すべて選択 | Cmd+A |
| 新しいフォルダ | Cmd+Shift+N |
| アドレスバーへ移動 | Cmd+L／Option+D |
| 検索 | Cmd+F／Cmd+E |
| 更新 | F5／Cmd+R |
| 新しいタブ／タブを閉じる | Cmd+T／Cmd+W |
| 新しいウィンドウ | Cmd+N |
| プロパティ | Option+Enter／Cmd+I |
| プレビューウィンドウの切り替え | Option+P |
| ナビゲーションウィンドウの表示切り替え | Cmd+Option+S |
| ナビゲーションウィンドウとファイル一覧の切り替え | Tab／F6 |
| ナビゲーションウィンドウ内の移動 | ↑↓（移動）、→（開く）、←（閉じる／親へ）、Enter（一覧へ戻る） |
| クイックルック | Space |
| 先頭の文字にジャンプ | 文字キーを入力する |

名前変更、アドレスバー、検索ボックスの入力中は、これらのキーは文字入力として扱われます。

## ファイル操作の安全策

- 削除は必ずゴミ箱への移動です。完全には削除しません
- 同名の項目があるときは「置き換える／スキップする／両方残す」を尋ねます
- 「置き換える」を選んだ場合も、元からあった項目はゴミ箱へ移します
- 移動、名前変更、削除、コピー、新規作成、ZIP の作成・展開は Cmd+Z で元に戻せます
- ドラッグ＆ドロップは、同じボリューム内では移動、別のボリュームへはコピーです。Option を押しながらドロップするとコピーになります
- 時間のかかる操作は進捗を表示し、キャンセルできます

## 他のアプリの「Finderで表示」を Tansu で開く

Claude Desktop やブラウザなどで「Finderで表示」を選んだとき、Finder の代わりに Tansu を前面に出し、対象の親フォルダを開いて、その項目を選択した状態にできます。

- **有効にする**：初回起動時の案内で「有効にする」を選ぶか、メニューの「Tansu > 設定…」（Cmd+,）でスイッチをオンにします。初期値はオフです
- **オフにする**：有効にする直前の表示先に戻します。元が未指定なら未指定に戻します。有効にした後で別のアプリが表示先に指定されていた場合は、その設定に触れません
- スイッチには、macOS で実際に指定されている表示先が反映されます

Tansuを削除する前に、設定でこのスイッチをオフにしてください。

仕組みは、macOS のユーザー単位の設定 `NSFileViewer`（ファイルの表示先）に Tansu を指定するものです。次のコマンドで現在の値を確認できます（未指定のときはエラーが表示されます）。

```bash
defaults read -g NSFileViewer
```

知っておくこと:

- **アプリの再起動が必要な場合があります**。一度でも「Finderで表示」を使ったアプリは、起動している間、切り替え前の表示先へ送り続けます。切り替えたあとは、そのアプリを再起動してください
- 対象の親フォルダをすでに開いているタブがあればそのタブを使い、なければ新しいタブで開きます
- フォルダが対象のときも、そのフォルダの中へ入るのではなく、親フォルダの中で選択します
- macOS はこの要求を「開く」要求として Tansu に送ります。そのため `open -a Tansu パス` のように Tansu で項目を開いた場合も、同じ動作（親フォルダを開いて選択）になります
- Finder を直接操作するアプリ（AppleScript で Finder に指示するものなど）は、この設定の対象外です

## AI 連携機能

アプリ自身は AI を呼び出しません。API キーの設定も、外部への通信もありません。
右クリックメニューの「AI」サブメニューに、次の機能をまとめています。

| 機能 | 内容 |
|---|---|
| 〜で開く | 対象フォルダでターミナルを開き、Claude Code や Codex を起動する |
| パスのコピー | 絶対パス、相対パス（Git リポジトリの最上位から）、`@相対パス` から選ぶ。複数選択時は改行区切り |
| AI用にコピー | 選択したファイルの内容を、ファイルごとに「相対パスの見出し＋Markdown コードブロック」にまとめてコピーする |
| フォルダ構成をコピー | フォルダ以下の構成を `tree` コマンドのような図にしてコピーする |

- 「AI用にコピー」「フォルダ構成をコピー」は、`.gitignore` の対象、`.git`、`node_modules` を除きます
- バイナリファイルと 1MB を超えるファイルは「AI用にコピー」から除き、除いたことを通知します
- `.env`、秘密鍵（`id_rsa`、`*.pem` など）、認証情報らしいファイルが含まれる場合は警告を出し、除外してコピーするかを選べます
- ファイルを選択すると、ステータスバーに推定トークン数を表示します（英数字は 4 文字で 1、それ以外は 1 文字で 1 とする概算です）
- Git リポジトリ内のフォルダでは、名前の横に変更状態（M／A／?）、ステータスバーにブランチ名を表示します
- プレビューウィンドウでは、Markdown ファイルを整形して表示します

### 設定ファイル

`~/Library/Application Support/Tansu/settings.json`（初回起動時に作成されます）

```json
{
  "agents" : [
    { "command" : "claude", "name" : "Claude Code" },
    { "command" : "codex", "name" : "Codex" }
  ],
  "aiFeaturesEnabled" : true
}
```

- `agents`：「AI」サブメニューに表示するエージェントと、ターミナルで実行するコマンド。追加・変更できます
- `aiFeaturesEnabled`：`false` にすると、AI サブメニュー、トークン数、Git の状態表示をまとめて非表示にします

編集後、Tansu のウィンドウに戻ると反映されます。

## Windows 11 エクスプローラーとの違い

- **ホーム**：ユーザーのホームフォルダ（`~`）を開きます。最近使ったファイルの一覧ではありません
- **フォルダの置き換え**：同名のフォルダを「置き換える」と、中身を統合せず、元のフォルダをゴミ箱へ移してから置き換えます
- **検索**：Spotlight によるファイル名の検索です。Spotlight の索引対象外の場所（一部のシステムフォルダや、索引を切っているボリューム）は検索できません
- **元に戻す**：やり直し（Redo）はありません
- **コピーのキャンセル**：ファイル単位で止まります。大きな 1 ファイルをコピーしている途中では止まりません
- **メニューバー**：macOS の流儀に合わせて残していますが、項目は最低限です。「作文ツール」「自動入力」は macOS が自動で追加する項目で、アプリ側からは消せません

次の機能は、意図して入れていません。
ライブラリ、ギャラリー、ネットワーク、OneDrive 連携、特大・中・小アイコン、並べて表示、コンテンツ表示、グループ化、項目チェックボックス、詳細ウィンドウ、一括名前変更、フォルダオプション、Finder のカラム表示・ギャラリー表示・スマートフォルダ・クイックアクション、アプリ内の AI チャット、クラウドの LLM へのファイル送信、AI による自動整理。
